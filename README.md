# 🏦 Mortgage Calculator (React + Vite)

A sleek, user-friendly mortgage calculator designed to help users plan their finances. This project was built using modern web development tools and follows a clean, component-based architecture.

## ✨ Features

- **Real-time Calculation:** Instantly calculates monthly repayments and total interest as you type.
- **Dual Mortgage Types:** Supports both "Repayment" and "Interest Only" mortgage models.
- **Modern UI:** Built from scratch with CSS (no UI libraries) for a lightweight and beautiful experience.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.

## 🛠️ Technologies Used

- **React:** For building the interactive user interface and managing state.
- **Vite:** The lightning-fast build tool for a modern development experience.
- **CSS3:** Custom styles, Flexbox, and Media Queries for responsiveness.
- **NPM:** For managing project dependencies.
